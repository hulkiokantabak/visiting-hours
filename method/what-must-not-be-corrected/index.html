Vitrine III

What must not be corrected

A proofreader, a typesetter, a copy editor or a later hand will meet a number of things in this book and reach for a pencil. Each of them is deliberate. Two files exist so that the hand which will not ask is told before it moves — one for each edition — and this vitrine measures those files rather than listing what is in them.

The Turkish file is the longer of the two, and it says why: Turkish offers a copy editor corrections the English never could — a diacritic to fix, a case ending to regularise, a missing comma to supply, a foreign-looking word to naturalise. Each of its notes was established by a census of the finished body and carries the count, so a later hand can re-run it rather than believe it.

The file did not reach the hands it was written for

The notes are handed to a verifier through a limb that matches a note to the piece it protects. The limb matched on the story’s title, and the notes name their homes in prose — story one, story fifty-eight, the companion’s entry. Two notes happen to print a title. The rest arrived as silence.

2 hits and 60 misses across sixty-two briefs. The limb matched a note by the story’s TITLE and the notes name their homes in PROSE — “story one”, “story fifty-eight”, the companion’s entry. Only two notes happen to print a title

docs/VERIFIER-LOG.md, row V-66. Each note now carries an invisible index of the pieces it protects, derived by census and not from the note’s own wording; delivery went from two of sixty to twelve of twelve.

Widened, the same matcher then delivered two notes to stories that do not carry them. The log files that beside the first fault and draws the line the pavilion works to: a matcher that reaches what it should not is the same fault as one that cannot reach what it should, and both were found by reading the matcher.

What this site does about it

A web typographer’s reflex destroys every one of those features, so the reflex is not installed. The builder applies exactly one transform to the book’s text — the print edition’s own typographer, borrowed from build/book.py rather than copied — and escapes three characters. There is no normaliser, no quote pass, no linter over the body, and there is no place to add one without removing a check.

Two standing checks carry that into the built pages. One asserts that the stylesheet property which folds a string’s case occurs in nothing the site ships, stylesheet included, because on the Turkish title that fold prints a dotless I. The other carries the print edition’s own typographic check to the web and fails the build if a straight quote or apostrophe reaches a page.

That property is named in build/site_lib.py and is deliberately not printed here. It is the second self-referential guard the pavilion met: a page that names the banned string fails the check that bans it, on the line that names it. The other is on the pavilion floor, where the census of resolving formulas cannot print the formulas it scans for. Both were caught by the site’s own limbs at the build that first wrote these pages, and neither check was widened to let the page through.

What is not on this page: which features they are. The notes exist so that a later hand does not correct them, and a list of them on a public page would be a different document with a different reader.
