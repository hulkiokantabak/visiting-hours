Vitrine I

The page that is not translated

One piece of the sixty is carried into the other edition unchanged. The book refuses to translate it, and the refusal is defended inside the fiction rather than in a note. This vitrine records the refusal. It does not record what the page says.

How the page is found

It is found, not remembered. The site reads both trees with each tree’s own body reader — the English from build/book.py, the Turkish from tools/vh_tr_checks.py, both borrowed rather than copied — and looks for the piece whose two bodies are identical. That is what carried untranslated means, so the site finds the page the way the law defines it. If a second piece ever answered to that criterion the build stops instead of guessing.

What the site does with it

The page is shown. It is marked lang="eo", so a screen reader is told which language it is in rather than made to read Esperanto as English. There is no gloss, no note, no tooltip, no translation toggle and no link to one. This site holds no translation helper for that page — deliberately: there is nothing here to reach for. Standing check S9 names the piece it found and asserts the page carries no gloss in either edition.

And the guard on the rule was blind

The check that guards this rule compared the two bodies as the builders read them — through Python’s universal newlines, which fold a carriage return away before anything is hashed. A divergence of twenty-five bytes was simulated and the check reported PASS, in the one limb whose entire subject is bytes, in a repository that warns about line endings on nearly every commit. The files had not drifted. The limb could not have seen it if they had.
